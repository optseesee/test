# ABC286C

## 問題文
長さ N の文字列 S が与えられます。S_i (1 ≤ i ≤ N) を S の左から i 番目の文字とします。

あなたは以下の 2 種類の操作を好きな順番で何回以上好きな回数行うことができます。
- A 円払う。S の任意の文字を任意の文字に変更する。すなわち、S_1, S_2, ..., S_N を S_2, ..., S_N, S_1 に変える。
- B 円払う。1 以上 N 以下の整数 i を選ぶ; S の好きな i 番目の文字を置き換える。

S を回文にするのに必要な最小の費用を求めてください。

## 制約
- 1 ≤ N ≤ 5000
- 1 ≤ A, B ≤ 10^9
- S は小文字からなる長さ N の文字列
- S は入力のたびに変動

## 入力
入力は以下の形式で標準入力から与えられる。

```text
N A B
S
```

## 出力
答えを整数として出力せよ。

## 入力例 1

```text
5 1 2
rrefa
```

## 出力例 1

```text
1
```
最初に 2 番目の操作を 1 回行います。2 円払い、i = 5 として S_5 を a で置き換えます。S は rrefe となります。

次に 1 番目の操作を 1 回行います。1 円払い、S は refer となります。これで 1 回以下です。

よって 3 円払うことで S を回文にすることができました。2 円以下払うことで S を回文にすることは不可能なので、これが答えです。

## 入力例 2

```text
8 1000000000 1000000000
bcdfcgaa
```

## 出力例 2

```text
4000000000
```
答えは 32 bit 整数に収まらない場合があることに注意してください。
